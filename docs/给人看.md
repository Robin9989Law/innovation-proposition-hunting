# 给人看

现在只做一件事：尽快找到最危险的那篇近邻。

最危险，是指这篇如果成立，你要写的那句话就被占住了，或者能从它推出来。不是引用最多的那篇，也不是期刊最好的那篇。

## 你要准备的

把你想写的那句话拆成两处：

- 对象：在说什么东西
- 动作：对它做了什么

两处都对上，才算碰上。只对上一处，丢掉。同义词只用你已经写过的叫法。

论文按你觉得最可疑的顺序放进去。每篇先只看题目和摘要，加上它的参考文献编号和被引编号。不读全文。

## 你要写的话

程序会一次只拿出一篇。你看完摘要里那一句，自己写：

- `是同一个东西`：这篇说的就是你的对象。然后再写这一句是 `占住`、`能推出来`，还是 `只是像`。
- `不是同一个东西`：这篇丢掉，换下一篇。

写成问句不算。程序不会替你决定是不是同一个东西。

`占住` 和 `能推出来` 才会成为锚点。`只是像` 就继续看下一篇。

## 找到之后

第一篇锚点出现，就不再往下扫名单。

然后只绕它一圈：它直接引用的前作，和直接引用它的后续。不看前作的前作，也不再拿关键词去搜。这一圈里的每篇，仍要对象和动作都对上，仍要你确认。

这一圈看完，判断没有变得更危险，就停。这里就够了。

圈上如果出现更危险的一篇，它变成新的锚点，圈只重画一次。

名单走完还没有这样一篇，就写看不清。不要把整个领域扫一遍，然后说这是蓝海。

## 命令

```bash
python3 <技能目录>/scripts/hunt.py init --root . --object "对象" --action "动作"
python3 <技能目录>/scripts/hunt.py add --root . --id 编号 --title "题目" --abstract "摘要" --references 前作编号 --cited-by 后续编号
python3 <技能目录>/scripts/hunt.py next --root .
python3 <技能目录>/scripts/hunt.py decide --root . --id 编号 --same "是同一个东西" --danger 占住
```

不是同一个东西时，不要写 `--danger`。
