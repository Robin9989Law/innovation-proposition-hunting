# 给人看

这个工具只做一件事：帮你把论文题目定下来。定不下来，就告诉你该停。

它不跑实验，也不替你写论文。题目定了以后，实验和写作另外做。

你不用背那些英文状态名。全程你只在五个地方亲自看一眼。中间那些步骤是在查文献、对证据，你不用盯着。

只回一句「继续」，等于没看。这五个地方必须等你用自己的话说话。程序离开下面四个状态时，必须带上你的原话；只写「继续」会被拦住。

每次做一个课题，单独建一个文件夹，卡片、文献名单、状态文件都放在那里。不要写进技能仓库，也不要摊在工作区根目录。

## 一共就这些路

主路五段，每段停一次。中间的英文状态是它自己记账，你不用跟。

1. 定范围。你点头。
2. 只查题目和摘要，写成研究卡片。你看这片是红海、蓝海，还是看不清，并说决心是大、中还是小。
3. 按决心挖近邻。决心小就少挖，红海可以直接停。决心大才把最强的那篇钻完。你点头。
4. 只读可能推翻那一句的论文。先钻进盖住你的那篇找缝，不许换个场景躲开。你看判断。
5. 换一个人看过那一句。你收下题目。到此结束。

走偏了，只剩下面这些，不要再长出别的流程：

| 实际情况 | 该怎么走 |
|---|---|
| 别人已经发过，或者用旧结果就能推出来 | 停在第 4 段。这就是做完，不用硬走到最后 |
| 还没查完，或者还没认真试过推翻 | 停着。你自己说了，才可以再查一轮，或者只改那一句 |
| 你认为「新」的判断是错的 | 撤回，回到还不能判。不许直接改成新的 |
| 换的那个人没通过 | 退回去改那一句，再看一次 |
| 你不想收这个题目 | 退回去改。不是转去做实验 |
| 全文下不来，或别的外部条件缺了 | 卡住。先别改结论 |
| 状态已经进了实验 | 叫它停。那是旧项目留下的路，新题不要走进去 |

## 用得差是什么样子

- 五个地方没停，一口气跑完
- 近邻表还没写，就下了一堆全文
- 抽了很多条，删掉以后，新不新的判断还是一样
- 说「新」的那一页，只有「据我们所知还没人做」
- 自己给自己盖章
- 为了走到最后，把已经做过的想法说成新的

用得好的时候，五页你都读得懂。它说新，就写了试过哪些推翻、为什么没推翻掉。它说停，就写了是哪一篇、哪一条。停掉也算做完。

## 想少等一会儿

长篇阅读之前，先在课题目录运行：

```bash
python3 <技能目录>/scripts/iph.py judge --root . --state workflow_state.json
```

它按现在走到哪，直接说三件事里的一件：停下来等人、同一段里继续记账、或者这个想法已经该停。不用再把整本说明读一遍才知道下一步。

有 Jev 的密钥时，可以加上 `--jev`。密钥放在环境变量 `TYPESAFE_API_KEY` 里，不要写进课题文件。它向官方接口发一次请求，看这一页像不像空话。没有密钥也能用，只是不看内容。

它不能代替你点头，也不能把「还不能判」说成「新」。该停的地方，快筛松不开。

## 先快后慢

研究卡片这一步只做快判。看题目和摘要，给一个大致判断：红海、蓝海，或者看不清。红海是已经有好几篇很近的论文做了那个顺手的想法。蓝海是眼前还看不见谁做了。这不是「新不新」的结论。

然后你说决心，慢路线才开：

| 决心 | 怎么挖 |
|---|---|
| 小 | 红海就停，不钻。蓝海只核对最像的一两篇。不许换个场景把旧想法说成新的 |
| 中 | 只钻最强的那一篇，问三句：它靠了什么自己没检查的承诺，它为什么停，边界露出了什么。没有缝就停 |
| 大 | 最强的那篇六问都要答完。缝必须是它自己没回答的问题。问完还没有，才允许停 |

决心大不会把红海说成新的。它只决定挖多深。离开这一步时，用自己的话说，例如：「这片是红海，我的决心中。」

## 多少篇才够判断

够不够，看再加一篇，判断会不会变。下载了多少，不算。

快判这一步全文是 0，只看题目和摘要：

- 已经有 3 篇很近的正式论文做了那个顺手的想法，就是红海。停，不必凑数。
- 还没有，就找到 8 篇跟这件事实质相关的正式论文，再给红海或蓝海。
- 然后再看 5 个新题目。判断不变，快判做完。
- 认真找过，相关的正式论文不到 8 篇，把实际找到几篇写上。不要用没找够冒充蓝海。

慢挖按决心停，不要读到上限才罢手：

| 决心 | 够了就可以停 |
|---|---|
| 小 | 红海：全文 0，快判已经够。蓝海：再核对 1 到 2 篇摘要 |
| 中 | 全文只读最强的 1 篇。看不出就再加 1 篇，到 2 篇为止 |
| 大 | 全文读能杀死这句话的那几篇，通常 3 到 5 篇。六问答完就停 |

12 篇、20 篇是不许超过的天花板。100 篇是不许再横向搜整个领域的天花板。都不是「读满了才算判断」。

## 你要看的五个地方

### 1. 开工之前

先把三件事说清楚：

- 这是博士论文，还是一篇期刊文章
- 新东西从哪来：别人还没做的空当，把现有工作往下做，还是用成熟办法把一个新问题讲清楚
- 最后交什么：新理论，旧理论用到新地方，新算法，还是把现有算法做深

这三件没说清，先别查文献。范围写进 `scope_lock.md` 之后，还要你再看一眼，点头了才能往下查。

你可以这样回：「这是期刊论文。我要把现有算法做深，不另起一套理论。」

### 2. 研究范围写下来以后

打开 `l1-card.md`，看三行就够：

- 研究的是什么
- 要对付的矛盾是什么
- 现在谁在做

这一步本来就不读全文。名单里的人和题目要是跟你想的不是一回事，现在就说。

范围和你说的是同一块，这步就过了。卡片里冒出你没提过的题目，或者把好几块研究捆在一起，就打回去。

你可以这样回：「范围对，就按这个往下。」也可以说：「某某不该算进来。」

### 3. 近邻表写出来以后

打开 `l2-card.md`。每篇要紧的邻居论文都要有三栏：

- 它到底做了什么
- 你哪个顺手的想法，因此不能再当创新
- 还剩下什么更硬的问题

有一栏是空的，这步就没做完。下了多少篇全文，不算数。

你认得这些论文，那些顺手的想法也确实被它们做掉了，这张表才算数。空话，或者漏了你知道的那篇，就让它补。

你可以这样回：「这张表我认。」也可以说：「漏了某篇，补上再停。」

### 4. 新不新判完以后

打开 `novelty-audit.md`。看最后的判断，以及它为什么这么判。

有四种结果：

- 别人已经正式发过同样的东西。停。这不是搞砸了，是及时停掉错方向。
- 没有同名论文，但套用已有结果就能推出来。也停。
- 还没查完，或者还没认真试过推翻它。先停着。这时不能说有创新，也不能开实验。
- 该试的推翻办法都试了，这句话还在。可以把这句话定下来。这仍然不是让你去跑实验。

判断里要有具体论文、具体结论，而且你能对上原文。只写「据我们所知还没人做」，又没写试过怎么推翻，就是在糊弄你。

你可以这样回：「我同意这个判断。」也可以说：「我不同意，某篇论文已经做了。」

还不能下结论时，如果要再查一轮，或者只改那一句，也要你自己说一声。不能它自己接着跑。

### 5. 收下题目之前

这时应该换过一个人，或者另一个程序，看过你的材料。不能它自己给自己盖章。

你看一页纸就行，上面只放这四样：

- 准备写进论文的那一句
- 它靠哪几篇论文站住
- 哪些相关想法明确不做了
- 实验还没做，论文也还没写

你要是同意，用自己的话写一句。这句话要让人看出：你收的是这次定题，而且就是这一次。句子里带上项目编号，或者那条已经定下来的主张编号。写「同意」和「题目」就行，不必凑黑话。

「继续」「把全流程做完」「我授权你去算」，都不算收下。

你点头之后，这个工具就到此为止。

## 怎么知道它对不对

程序说 READY，只说明文件格式过了，不说明题目真的新。

你就查四件事：

1. 五个地方都停下来问过你，不是一口气跑完。
2. 让你打开的文件，你读得懂，讲的也是你的课题。
3. 它说「新」的时候，写了试过哪几种推翻，以及为什么没推翻掉。
4. 它说「该停」的时候，写了是哪篇论文已经做了，或者怎么从旧结果推出来。停掉是正常结果。

想看现在走到哪了，在课题文件夹里运行：

```bash
python3 <技能目录>/scripts/iph.py explain --root . --state workflow_state.json
```

它会用大白话告诉你现在在哪一步、要不要你做决定、该打开哪个文件。

## 听到黑话时查这张表

| 它说的 | 意思 |
|---|---|
| 博士论文 | 要三个连得上的贡献 |
| 期刊论文 | 只要一个主贡献 |
| 地盘，L1 | 研究范围，还不是创新点 |
| 战场，L2 | 范围里值得做的那一小块 |
| 命题，L3 | 准备写进论文的那一句，得能被推翻 |
| 邻居 | 离你最近的已有论文 |
| 冻结 | 这句话定死了，后面不许偷偷改字 |
| 关掉，N0-1、N0-2 | 这个想法不做了 |
| 还不能判，N0-3 | 先停，别宣布有创新 |
| 还活着，N0-4C | 推翻没成功，可以把这句话定下来。不是开实验 |
| READY | 格式过了。不是科学结论 |
| 卡住 | 缺外部条件，比如下不了全文。先别改结论 |
