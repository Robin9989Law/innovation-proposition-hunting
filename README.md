最近的那一篇只是跳板。先核对四件事：近邻是不是真的近，能不能通过它找到圈子，紧密程度有没有数对，进核心是不是有限步。这一轮只看近三年的直接邻居。全程只看题目和摘要。内核不紧密、这一团被否散、或汇合点摘要里看不见缝，就换近邻，最多换 10 次。
