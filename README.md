# 创新命题狩猎

最近的那一篇只是跳板。近三年只限制最多看多少篇。全程只看题目和摘要，不必读全文。它旁边要先有紧密的主题生态：每篇至少连着两篇。内核不紧密，或者指不到主题核心，就换近邻，最多换 10 次。找到之后沿最短的路直指主题核心，按摘要写下开放命题。

人先看 [docs/给人看.md](docs/给人看.md)。程序看 [SKILL.md](SKILL.md)。

```bash
python3 scripts/hunt.py init --root <课题目录> --object "方向里的对象" --action "方向里的动作"
python3 scripts/hunt.py next --root <课题目录>
```
